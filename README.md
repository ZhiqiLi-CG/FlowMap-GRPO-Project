# Flow-Map GRPO project page

Static research project page for Flow-Map GRPO ([arXiv:2607.00535](https://arxiv.org/abs/2607.00535)). Code: [ZhiqiLi-CG/FlowMap-GRPO](https://github.com/ZhiqiLi-CG/FlowMap-GRPO).

GitHub Pages: deploy from the `main` branch, `/ (root)` directory. No build step required.

Preview locally: `python3 -m http.server 8000`.

All images and numbers come from the paper. The interactive examples are the appendix Base/Ours step sweeps, cropped into per-step tiles; `asset-provenance.json` records the source figure of each asset.
